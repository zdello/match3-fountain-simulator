플레이어 이동

이동 모드에서 첫 타일과 상하좌우로 인접한 두 번째 타일을 차례로 클릭합니다. 매치가 없으면 원래 위치로 돌아가며, 중력 이후 새로 생긴 매치도 연쇄적으로 계속 처리됩니다.

강조 표시

강조 모드에서 타일을 클릭하면 굵은 테두리를 켜거나 끌 수 있습니다.

오리 오브젝트

오리는 분수의 가장 바깥 물길 링에만 직접 배치합니다. 오리는 분수 회전 시 이동 판정을 받으며, 타일 제거 상황에서는 오리 바로 앞칸이 실제로 제거된 경우에만 중력보다 먼저 이동합니다. 둘 다 중력의 영향을 받지 않습니다.

자유형 분수

연결된 칸을 직접 선택해 분수 몸체를 만듭니다. 선택한 도형의 바깥을 1칸 두께로 둘러싸는 물길이 자동 생성됩니다.

사각형 분수

가로/세로를 각각 지정할 수 있습니다. 가장 바깥 1칸은 회전하는 물길이며, 내부 영역은 고정 분수 오브젝트입니다.

편집

중력 처리, 회전, 제거, 직접 배치 등 보드가 바뀌기 전 상태로 돌아갑니다.

단계형 턴 처리

1. 분수 회전
설정 방향으로 링 타일 1칸 이동
2. 매치 판정
가로/세로 3개 이상 표시
3. 제거 / 특수 생성
2×2 또는 4개 이상 특수 조건이면 특수 아이템 1개를 남기고 나머지를 제거
4. 중력 처리
수직 낙하 → 수직 진입 불가 시 좌/우 대각선 낙하 → 상단 보급
직접 비워둔 빈칸도 이 버튼으로 즉시 중력/보급 처리할 수 있습니다.
